# Words & Expressions Commonly Misused — the Sweep A lookup list

Strunk's Chapter V, pruned to what still bites in modern caption prose, plus a marked
section of LinkedIn-native filler he never saw. Use as a scan list during Sweep A:
grep-by-eye each entry against the caption.

Strunk's framing (worth keeping in mind): some of these "are good in their place, but
are constantly obtruding themselves into places where they have no right to be." And
his repair advice: when one has slipped in, usually don't patch the sentence by swapping
one word — **recast the sentence completely**.

## Strunk's entries (still live)

| Entry | Problem → Fix |
|---|---|
| **as good or better than** | Rearrange: "My opinion is as good as his, or better." |
| **as to whether** | "whether" is sufficient. |
| **but (after doubt/help)** | "I have no doubt but that" → "I have no doubt that". |
| **but… But… (chained)** | A contrast to a contrast reads as zigzag. Rearrange so one "but" carries it. |
| **case** | "In many cases, the rooms were poorly ventilated" → "Many of the rooms were poorly ventilated." Usually deletable. |
| **certainly** | An indiscriminate intensifier, like "very". Cut. |
| **character / nature** | Redundant padding: "acts of a hostile character/nature" → "hostile acts". |
| **claim (vb)** | Means "lay claim to". Not a substitute for declare/maintain/charge. |
| **dependable** | Needless substitute for reliable, trustworthy. |
| **different than** | → different from / other than / unlike. |
| **due to** | Not adverbial: "He lost, due to carelessness" → "through/because of carelessness". Fine as a predicate: "losses due to preventable fires". |
| **effect (vague noun)** | "a charming effect", "broad effects" — refuge of the writer with no definite meaning. Name the thing. |
| **etc.** | Not after "such as / for example". Not when the reader is left guessing what it hides. |
| **fact** | Only for the directly verifiable. "The fact that" → revise out every time (Rule 13). |
| **factor** | Hackneyed. "His training was the great factor in his winning" → "He won by being better trained." |
| **feature** | Adds nothing. Tell what the thing IS instead of calling it a feature. |
| **he is a man who** | → "he". "Spain is a country which I have always wanted to visit" → "I have always wanted to visit Spain." |
| **however (sentence-first)** | Meaning "nevertheless", it shouldn't open the sentence: "At last, however, we succeeded." Opening "However" means "in whatever way". |
| **interesting** | Never announce that a thing is interesting — make it so. "An interesting story is told of…" → tell the story without preamble. |
| **kind of / sort of** | Not a hedge for "rather / something like". Keep the literal sense only. |
| **less vs fewer** | Less = quantity, fewer = number. "Fewer meetings", not "less meetings". |
| **like vs as** | "Like" governs nouns; before clauses use "as": "He thought as I did." |
| **line / along these lines** | Overworked to death; discard entirely. "He is studying along the line of French literature" → "He is studying French literature." |
| **literal / literally** | Not a prop for exaggeration: "literally dead with fatigue" → "dead tired". |
| **lose out / win out / try out / sign up (padded verbs)** | Meant emphatic, actually weaker. "Lose" beats "lose out". (Idioms with distinct meanings — find out, turn out, make up — stay.) |
| **most (for almost)** | "Most everybody" → "almost everybody". |
| **one of the most** | Threadbare opener ("one of the most interesting developments…"). Never open a caption block with it. |
| **phase** | A stage of transition ("the phases of the moon"), not a synonym for aspect/topic. |
| **possess** | Mere substitute for have/own. "He possessed great courage" → "He had great courage." |
| **respective(ly)** | Usually deletable with advantage. |
| **so (intensifier)** | "so good", "so fast" — avoid in writing. |
| **state (vb)** | Not a substitute for say/remark. Restrict to "express fully". |
| **system** | Frequently used without need: "the dormitory system" → "dormitories". Watch "our AI system for X" → often just "our AI" or the product name. |
| **very** | Use sparingly. Where emphasis is needed, use words strong in themselves. |
| **viewpoint** | Prefer "point of view"; don't misuse either for "opinion". |
| **while** | Only for "during the time that". Not a variety-substitute for and/but/although — a semicolon or "although" says it honestly. |
| **worth while** | Vague approval. Say what the thing repays: "not worth reading", not "not worth while". |
| **would (habitual)** | "Once a year he would visit" → "Once a year he visited." Plain past is shorter and stronger. |

## Consciously excluded from Strunk's list

- **They (singular)** — Strunk demands "he"; modern usage (and our house style) uses
  singular they. Excluded as obsolete.
- **Shall/will, should/would (person rules)** — archaic distinction; dead in modern prose.
- **Split infinitive** — Strunk-era disfavor; now acceptable when it reads better.
- **All right, bid, can/may, consider-as, data-plural, don't/doesn't, fix, folk, get/got,
  near by, oftentimes, one hundred and one, participle-for-verbal-noun, people/public,
  prove(d), student body, thanking you in advance, whom-for-who** — grammar-book or
  period concerns that modern caption prose doesn't trip on. Cut for signal density.

## LinkedIn-native filler (additions — not Strunk)

Same disease, current strains. Cut or recast on sight:

| Filler | Why it's fat |
|---|---|
| In today's world / In today's fast-paced landscape | Announces "now" — every post is now. |
| At the end of the day | Verbal throat-clearing before the point. |
| The truth is / Honestly / Let's be real | Implies everything above it wasn't. |
| Let me explain / Let me break it down | The next line will do that or won't; the promise adds nothing. |
| What this means is / The reason for this is that | Scaffolding; state the meaning directly. |
| It's worth noting that / It's important to note | If it's worth noting, note it. |
| game-changer / next level / unlock / supercharge | Promo puffery (humanizer territory too, but cut it here first). |
| a majority of / a number of | "most" / "some", or the actual number. |
| in order to | "to". |
| the ability to X | Usually "can X". |
| going forward / moving forward | The tense already says it. |

Note: "Here's the… / here's the thing" is voice-profile signature and NOT on this list.
Keep it.
